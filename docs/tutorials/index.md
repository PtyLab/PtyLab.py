# Tutorials

Hands-on tutorials covering CPM and FPM reconstruction from simulation and real data.

## In this section

- [**01 – CPM Simulation**](tutorial_CPM_sim.md) — Simulate a CPM dataset and reconstruct it end-to-end.
- [**02 – CPM Example Data**](tutorial_CPM.md) — Reconstruct a real CPM dataset using `easyInitialize`.
- [**03 – CPM Multi-Wavelength**](tutorial_CPM_multiWavelength.md) — Handle datasets acquired with multiple illumination wavelengths.
- [**04 – CPM Position Correction**](tutorial_LateralPositionCorrection.md) — Correct lateral probe-position errors during reconstruction.
- [**05 – CPM Reflection**](tutorial_reflectionPtychography.md) — Reconstruct data from a reflection-mode ptychography setup.
- [**06 – CPM Interferometric Intensity**](tutorial_interferometricIntensityConstraint.md) — Apply an interferometric intensity constraint during reconstruction.
- [**07 – FPM**](tutorial_FPM.md) — Reconstruct a Fourier ptychography dataset from LED-array images.

## Running a tutorial yourself

Every tutorial page has buttons to download it as a Jupyter notebook or as a Python script. Run the script with `python tutorial_CPM_sim.py`. The scripts are also in [`docs/tutorials/`](https://github.com/PtyLab/PtyLab.py/tree/main/docs/tutorials) in the repository.
